# Charlotte Real Estate Research

Personal research hub for real estate in **Charlotte (CLT), North Carolina** — and the home of a personal app to streamline that research.

## Goals
- Track neighborhoods, properties, and market trends across Charlotte / Mecklenburg County
- Keep notes, comps, and deal analyses in one place
- Build a personal app that automates the repetitive parts (data pulls, comps, cash-flow math)

## Layout
| Path | Purpose |
|---|---|
| `app/` | The personal research app (stack TBD) |
| `data/raw/` | Raw downloads (gitignored by default) |
| `data/processed/` | Cleaned datasets worth versioning |
| `notes/neighborhoods/` | One markdown file per neighborhood |
| `notes/properties/` | One markdown file per property under review |
| `docs/` | Research plan, data sources, app roadmap |
