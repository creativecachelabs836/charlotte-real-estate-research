# App Roadmap

## MVP ideas
1. **Property tracker** — save addresses, status, notes, links
2. **Deal analyzer** — mortgage, taxes, insurance, rent → cash flow, cap rate, CoC return
3. **Neighborhood dashboard** — price/rent trends per neighborhood
4. **Data pulls** — scripts to fetch county parcel and listing data into `data/`

## Later
- Map view of tracked properties and zoning
- Alerts for new listings matching criteria
- Comp finder by radius / sqft / year built
